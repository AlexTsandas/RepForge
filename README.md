# RepForge

RepForge is a fitness app for creating routines, logging workouts, and tracking strength progression. Planned AI features include routine generation, exercise validation, and workout reports comparing performance over the previous six weeks.

## Tech stack

- Frontend: React, Vite, TypeScript, Tailwind CSS, Axios
- Backend: Node.js, Express
- Database: MongoDB, Mongoose
- Authentication: Clerk
- Rate limiting: Upstash Redis
- AI: Google Gemini

## Progress so far

- Express backend is running.
- MongoDB connection is configured and working.
- Clerk SDK, middleware, and development environment keys are configured; protected-route testing is next.
- Git repository and GitHub remote are set up.

The frontend and fitness features are still to be built. This README will be updated with each commit.
